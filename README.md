# ScholarWeb

ScholarWeb is a syllabus-intelligent study platform scaffold with an initial backend + modern UI prototype.

## Implemented Foundation

- Syllabus DNA upload endpoint and UI form
- Syllabus-aware webpage analysis endpoint
- Live knowledge graph update endpoint
- Lecture intelligence endpoint
- Misinformation verification endpoint
- Exam countdown engine endpoint

## Run locally

```bash
npm start
```

Open `http://localhost:3000`.

## Test

```bash
npm test
```
